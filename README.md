# مطعم أبو حبيبه — قائمة الطعام

موقع قائمة طعام باللغة العربية، مبني باستخدام Next.js وReact. يتيح للزوار تصفح الأقسام والمنتجات، إضافة الأصناف إلى السلة، ثم إرسال الطلب عبر واتساب.

## التشغيل محليًا

```bash
npm install
npm run dev
```

افتح [http://localhost:3000](http://localhost:3000) في المتصفح.

## الصفحات والميزات

- `/` الصفحة الرئيسية والعروض وأقسام القائمة.
- `/menu/[category]` منتجات كل قسم وإضافتها إلى السلة.
- `/admin` تعديل المنتجات والعروض وإعدادات التواصل.
- `/admin/qr` إنشاء رمز QR لرابط القائمة وتنزيله.
- الطلبات تُرسل إلى واتساب بالمنتجات والكميات والإجمالي.

## البيانات

قائمة البداية موجودة في `data/menuData.ts`. يقرأ الموقع البيانات المشتركة من Supabase، ويحتفظ بنسخة محلية احتياطية للعرض عند تعذر الاتصال.

### إعداد قاعدة البيانات والدخول للوحة الأدمن

1. أضف رابط Supabase والمفتاح العام والمفتاح السري للخادم إلى `.env.local`. لا تضف `SUPABASE_SECRET_KEY` إلى أي متغير يبدأ بـ `NEXT_PUBLIC_` ولا ترسله للمتصفح. يمكن استخدام `SUPABASE_SERVICE_ROLE_KEY` للمشاريع القديمة.
2. اضبط `ADMIN_PASSWORD` و`ADMIN_SESSION_SECRET` في `.env.local` محلياً، وفي متغيرات بيئة الاستضافة عند النشر.
3. شغّل `database/schema.sql` مرة واحدة من SQL Editor في مشروع Supabase.
4. أعد تشغيل الموقع. بعد أول دخول للأدمن، تُرفع البيانات الموجودة على جهاز الإدارة إلى الموقع المشترك.

تطلب مزامنة البيانات بين الأجهزة مفتاح الخادم السري وتجهيز الجدول في Supabase. عند غيابهما يوضح الأدمن أن التعديلات محفوظة على الجهاز الحالي فقط.

تسجل الطلبات الجديدة في جدول `orders` عند تفعيل قاعدة البيانات، ويمكن تحديث حالتها من `/admin/orders`. تظل رسالة واتساب جاهزة للإرسال من العميل بعد فتح المحادثة.
